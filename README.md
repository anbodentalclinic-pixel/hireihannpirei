# 比例と反比例 ブロックで考える

中1数学「比例と反比例」の意味を、ブロックを動かしながらつかむための学習アプリです。
式の「a」が何を表しているのか（比例は「1つあたりの量」、反比例は「全体の量」）を見つけることがねらいです。

## ステージ

1. **長方形をさがす**：24個のブロックで長方形を作る。右上の角の点が反比例のグラフになる
2. **変わらないもの**：よこ×たてがいつも24になることを見つける（反比例の a ＝ 全体）。x＝0がないのでグラフが軸にくっつかないことも確かめる
3. **4個ずつの壁**：1列4個の壁を作る。全部÷列がいつも4（比例の a ＝ 1つあたり）。グラフは原点を通る直線
4. **見分ける**：場面を「比例・反比例・どちらでもない」に分ける（ワークで間違えやすい場面を使用）
5. **式を作る**：「aは何？」→ a を計算 → 式 → たしかめ、の順に8問
6. **紙でやる**：ワークでは、式を書く前に「aは○○」と一言書く

## 使い方

- スマホでもパソコンでも動きます
- 進み具合はそのブラウザの中だけに保存されます（外には送りません）
- 選ぶ問題は1回だけ答えられます。まちがえた場面や式の問題は、数を変えてもう一度出ます
- ブロックや壁は、予想を入れてからでないと並べられません
